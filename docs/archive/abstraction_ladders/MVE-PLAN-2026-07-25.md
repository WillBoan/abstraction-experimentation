## Strategy

**MVE-first, then expand.** Build the smallest set that runs end-to-end (certificate + climbs + raw arms + report) and yields the headline measurements; every further axis is an _expansion of a running set_, not a prerequisite. The uniform grid (~tasks x cohorts x sub-cohorts x members) is a coverage aspiration for the full set, not a requirement on the MVE — sampling the space matters, forcing symmetry does not.

## What the MVE is for

The ladder formalism is the lab's instrument for **axis 2 — the search-cost graph** ([docs/archive/RESEARCH-2026-07-08.md](../RESEARCH-2026-07-08.md)). Every reading it has produced is synthetic (al1-al20). **The MVE is that instrument's first reading on real ARC tasks**, and its headline is the 07-24 plan's goal 1: _does a real ARC task host a certifiable ladder, or does cheap perception erase the gaps?_ A broad collapse confirms Family-B on real tasks and redirects the program toward laddering perception itself — which Cohort B already is, so the MVE samples both sides of that question rather than betting on one.

**RQ coverage** (design doc §4), stated so the absences are deliberate:

| RQ | MVE status |
| --- | --- |
| **RQ1** — amortization (raw vs laddered) | One measured-or-bounded ratio per cohort. Expect uniform censored bounds: the screen _requires_ raw-intractability, so `>= K x` is near-guaranteed and carries the same content in every cohort (precedent: al15-al20 — six ladders, six identical `>= 10x`). RQ1 qualifies the set ("worth laddering at all"); it is not the headline. |
| **RQ2** — effect of design choices | **Granularity axis only** — cut density within a sub-cohort, where raw cancels and the comparison is fully measured. Decomposition-strategy (second sub-cohorts) and floor-power (cohort ablation) are wave 2. |
| **RQ3** — effect of what AF sees | **Out of scope.** Needs top-K retention / fragment selectors (design doc §6 deferred); no machinery exists. |

**Where the information actually is.** Because RQ1's bounds will be uniform, the MVE's quantitative core is the _within-cohort measured_ set — all of it already computed off recorded atoms: **marginal rung value** per rung, the **granularity curve** (cost vs cut density), the **loop-overhead factor** (raw cancels, so it is exact even under censoring), and **recovery / junk / cascade** per member. New read-side views need no re-run (design doc §3.5); the MVE's job is to produce the atoms.

Per-cohort and within-sub-cohort comparisons are the licensed ones.

## The corrected cost model

What the audit + alignment session established about what actually drives MVE cost. **Cheap or fine (not constraints):**

- **Large `d_raw`.** The task screen _requires_ raw-intractability, and RQ1 is measured-or-bounded (AL-PLAN-2026-07-23 decision 1): a censored raw arm is a proven `>= K x` bound, not a failure, and its compute is guarded at `K x laddered` regardless of `d_raw`. There is **no target `d_raw` band**; the only hard lower bound is "not raw-solvable from the floor" — already a lint (`raw-intractable`).
- **Many rungs.** Structurally fine; the cost that scales with rung count is demo authoring (below), not science.
- **Custom floor primitives.** Admissible when a task earns them. The promotion loop exists and worked (item 15/16); cross-task comparisons are unlicensed anyway (raw only cancels within a cohort), so a bespoke floor corrupts no comparison the program actually makes. It is per-task authoring cost, bounded — a line item, not a disqualifier.
- **Raw arms.** Bounded compute via the K-guard; one per cohort; not a shaping constraint.

**The real cost centers:**

1. **Demo plans per rung** — the dominant, linear-in-rungs cost, and exactly what blocks v5-core today: the `free-param-varies` class (every demo feeds a param the same value-pattern, so sleep would specialize instead of minting at intended arity — the S-B law). Tooling covers the _check_ side (lint/probe, seconds) but the _select_ side is manual.
2. **Unfold blowup on shared DAGs** — a mechanical defect, not a design limit: `substitute_params` duplicates subtrees, so unfolding a many-rung DAG with high fan-out can go exponential in term size at modest `d_raw` (v5-full's non-termination). Gates only tall shared-DAG ladders; fix deferred with them.
3. **Per-task fixed cost** — a verified solution term over the substrate + a pool of task-realizable grids + (sometimes) new primitives with ground-truth validation.

## Design disciplines (carried forward, binding)

- **Constant policy per floor kind**: `finite-enumerate-scalars` on addressing-tier floors (the Phase-0 probe's >20x finding — coordinates come from perception, small direction literals from scalars); off/minimal wherever a perceiver route covers everything. Phase-1 cohorts stay clean depth experiments (BREADTH-AXIS).
- **Natural mixed depths** — do not uniformize to all-d2; the certificate is a per-rung verdict profile, not a sandwich gate (CERTIFICATE-PROFILE; `double-jump-intractable` is warn-severity as of 2026-07-25's working tree).
- **Budgets derived from each member's validity window** (default: window minimum; global `depth_limit` = max rung depth until per-rung budgets land in Phase 2).
- **Parameterization declared per sub-cohort**, documented as the bind-early/bind-late choice it is.
- **Everything gated before it runs**; no ladder authored without its demo plan checked (`free-params-covary`, `free-param-varies`, probe).
