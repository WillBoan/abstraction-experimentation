**Goal [C].** The artifact is the _machinery_ — a solver that forms abstractions, plus the search and **governance** that decide which sub-programs earn a name, when to retire one, and how to keep the library searchable. The learned library is _observed, not targeted_; ARC score is a gauge, never the objective.

**The bootstrap cycle [H].** low floor + weak machinery → solve small-gap tasks → _compress_ solutions into abstractions → abstractions _speed up search_ → machinery bridges a _wider gap_ → repeat. The floor descends and the ceiling rises because the middle fills in. (DreamCoder-shaped.)

**Levers — a factorial design; move one at a time [H].**

- **Floor** (`substrate/`) — the primitive vocabulary. A vector: grain × paradigm (pure `build_grid` vs. stateful `set_cell`, which can read the partial canvas) × gifted control. Principle: _gift control, withhold domain_ **[C]**. Prefer intensional (rule) over extensional (per-cell trace) representations.
- **Curriculum** (datasets / eval slices) — which tasks, in what order. The real-input half of the old "target abstractions."
- **Machinery** (`search/`, `cost.py`, `Library.extended`) — search + a compression pass **[O]** + governance objective = two-part MDL `DL(sols|lib) + DL(lib)` **[H]**.

**Metrics — grain matters.** Units nest: **experiment ⊃ run ⊃ task ⊃ program** ("run" = one wake/sleep iteration). Each metric has a base grain, aggregates upward, and is either a _level_ or a _delta over an axis_ (runs, or the train↔held-out split).

| Metric | Grain | Level / Δ | Role |
| --- | --- | --- | --- |
| Program size / DL | per-program | level | base for compression |
| Solved? | per-task | level | base for solve-count / transfer |
| Nodes-to-solve | per-task | level | base for speedup |
| **Compression** | per-run | Δ (pre/post compress) | governance _objective_ — never self-grade **[C]** |
| **Transfer** | per-experiment | Δ (train↔held-out) | the _grade_ |
| **Search speedup** | per-task | Δ (with/without abstraction) | tractability bridge |
| Library growth / parsimony | per-run | level + Δ | is the wheel turning |
| Observed abstractions | per-experiment | qualitative | the demoted "targets" — surprise is the win |
| Solve count | per-run | level | sanity gauge only |

**Disciplines [C]:**

- Targets → observables: never optimize toward a _named_ abstraction.
- Optimize compression, **report** transfer, **diagnose** with the compression↔transfer correlation (it tests the MDL premise). Metric-that-drives ≠ metric-that-grades.
- A negative at a low floor indicts _Floor × Machinery_, never the floor alone.
- Preserve regression locks; keep determinism; `make check` green.
